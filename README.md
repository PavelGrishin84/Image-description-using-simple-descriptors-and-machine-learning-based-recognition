# Описание изображений простыми дескрипторами и распознавание объектов на основе сравнения с эталоном

MATLAB-скрипт [`Image_description_and_ML_recognition.m`](Image_description_and_ML_recognition.m), в котором изображения описываются простыми статистическими дескрипторами, а затем на этих дескрипторах обучаются и оцениваются несколько моделей машинного обучения для распознавания (классификации) изображений.

## Наборы данных

Скрипт рассчитан на работу со следующими наборами изображений (доступны на Kaggle):

- **notMNIST** — изображения букв английского алфавита ([kaggle.com](https://www.kaggle.com));
- **Fashion MNIST PNG** — изображения одежды ([kaggle.com](https://www.kaggle.com)).

Изображения должны быть организованы в подпапках, имена которых соответствуют классам (метки берутся из имён папок — `LabelSource`, `foldernames`).

## Требования

- MATLAB с Toolbox **Image Processing** (функции `imread`, `imbinarize`, `imageDatastore`);
- **Statistics and Machine Learning Toolbox** (`fitcensemble`, `fitcnet`, `fitcecoc`, `templateSVM`, `confusionchart`);
- **Parallel Computing Toolbox** (для ускорения вычисления дескрипторов через `parfor`); при его отсутствии замените `parfor` на `for`.

## Структура скрипта

### 1. Загрузка изображений

Доступ к файлам изображений получается через `imageDatastore` по пути, заданному в переменной `imdDir`:

```matlab
imdDir = imageDatastore('C:\Users\gps.84\Downloads\archive\test', ...
    "IncludeSubfolders", true, "LabelSource", "foldernames");
```

> Путь к папке с данными необходимо изменить на свой. Для перехода от тренировочного набора к тестовому соответствующие строки закомментированы/раскомментированы в скрипте.

### 2. Вычисление дескрипторов

Для каждого изображения:

1. изображение загружается (`imread`);
2. выполняется пороговая глобальная бинаризация (`imbinarize(I,'global')`);
3. считаются проекции — суммы значений пикселей по столбцам `X` и по строкам `Y`;
4. формируются четыре варианта дескрипторов:

| Дескриптор | Размерность | Описание |
|---|---|---|
| `D_1` | 2·28 | конкатенация проекций `[X, Y]` |
| `D_2` | 28 | разность проекций `X − Y` |
| `D_3` | 28 | модуль разности проекций `abs(X − Y)` |
| `D_4` | 4 | статистики дескриптора `D_1`: среднее, СКО, мода, медиана |

Вычисления выполняются параллельно (`parfor`), время работы измеряется `tic`/`toc`. Ошибки чтения файлов отображаются сообщением.

### 3. Обучение моделей

На выбранном дескрипторе (по умолчанию `D_1`) обучаются четыре классификатора:

- **Ансамбль ближайших соседей (KNN)** — `fitcensemble`, метод `Subspace`, 30 базовых обучений;
- **Ансамбль деревьев решений (TREE)** — `fitcensemble`, метод `Bag`, 30 базовых обучений;
- **Полносвязная нейронная сеть (NeuralNetwork)** — `fitcnet`, один скрытый слой из 100 нейронов, активация `relu`, стандартизация признаков;
- **Машины опорных векторов (SVC)** — `fitcecoc` (one-vs-one) с полиномиальным ядром 2-й степени (`templateSVM`).

Ожидается 10 классов (цифры `0…9`), список классов задаётся переменной `classNames`.

### 4. Распознавание и оценка точности

Каждая модель применяется к дескрипторам тестовых изображений (`predict`), для неё строится диаграмма ошибок (`confusionchart`) с нормализацией по строкам и столбцам, а усреднённое значение точности классификации выводится в консоль.

## Как использовать

1. Скачать один из наборов данных (notMNIST или Fashion MNIST PNG) и распаковать его.
2. Указать путь к папке с изображениями в переменной `imdDir` (в секциях загрузки тренировочных и тестовых данных).
3. При необходимости скорректировать список классов `classNames` под используемый набор.
4. Запустить скрипт целиком (**Run**) или по секциям (кнопка **Run Section**).
5. По результатам оценить матрицы путаницы и точность каждой модели; при желании выбрать другой дескриптор, изменив строку `DESCRIPTORS = D_1;`.

## Примечания

- Изображения предполагаются размером 28×28 пикселя (как в notMNIST/Fashion MNIST); размерности дескрипторов завязаны на это.
- В текущей версии скрипта переменная `Acc` (точность) в блоке вывода результатов не вычисляется явно — при необходимости её можно получить из диаграммы ошибок, например как среднюю по диагонали матрицы путаницы, либо через `sum(label == pred) / numel(label)`.
