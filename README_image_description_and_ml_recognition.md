# Описание изображений простыми дескрипторами и распознавание объектов (Python)

Python-скрипт [`image_description_and_ml_recognition.py`](image_description_and_ml_recognition.py) — порт MATLAB-скрипта [`Image_description_and_ML_recognition.m`](Image_description_and_ML_recognition.m). Изображения описываются простыми статистическими дескрипторами, а затем на этих дескрипторах обучаются и оцениваются несколько моделей машинного обучения для распознавания (классификации) изображений.

## Наборы данных

Скрипт рассчитан на работу со следующими наборами изображений (доступны на Kaggle):

- **notMNIST** — изображения букв английского алфавита ([kaggle.com](https://www.kaggle.com));
- **Fashion MNIST PNG** — изображения одежды ([kaggle.com](https://www.kaggle.com)).

Изображения должны быть организованы в подпапках, имена которых соответствуют классам (метки берутся из имён папок — аналог `LabelSource`, `foldernames` из `imageDatastore`).

## Требования

- Python 3.8+;
- библиотеки: **numpy**, **scipy**, **scikit-learn**, **Pillow**, **matplotlib**.

Установка:

```bash
pip install numpy scipy scikit-learn pillow matplotlib
```

## Структура скрипта

### 1. Загрузка изображений — `load_dataset()`

Список файлов путей и метки классов собираются из подпапок директории, заданной в константе `DATA_DIR`:

```python
DATA_DIR = "C:/Users/gps.84/Downloads/archive/test"
```

> Путь к папке с данными необходимо изменить на свой. Поддерживаются файлы `.png`, `.jpg`, `.jpeg`, `.bmp`, `.gif`.

### 2. Вычисление дескрипторов — `compute_descriptors()`

Для каждого изображения:

1. изображение загружается через Pillow (`Image.open`);
2. выполняется пороговая глобальная бинаризация (анал `imbinarize(I,'global')` — порог Отсу на нормализованном ярком изображении, функция `_otsu_threshold()`);
3. считаются проекции — суммы значений пикселей по столбцам `X` и по строкам `Y`;
4. формируются четыре варианта дескрипторов:

| Дескриптор | Размерность | Описание |
|---|---|---|
| `D_1` | 2·28 | конкатенация проекций `[X, Y']` |
| `D_2` | 28 | разность проекций `X − Y'` |
| `D_3` | 28 | модуль разности проекций `abs(X − Y')` |
| `D_4` | 4 | статистики дескриптора `D_1`: среднее, СКО, мода, медиана |

Время вычисления измеряется через `time.time()` (анал `tic`/`toc`). Файлы, которые не удалось прочитать, помечаются сообщением «Ошибка чтения файла!» и исключаются из выборки.

### 3. Обучение моделей — `train_models()`

На выбранном дескрипторе (по умолчанию `D_1`) обучаются четыре классификатора, соответствующие моделям из MATLAB-скрипта:

- **Ансамбль ближайших соседей (KNN)** — класс `SubspaceKnnEnsemble`: метод Subspace (случайные подпространства по 28 признаков), 30 базовых KNN-обучений (k=5) — аналог `fitcensemble(..., 'Method','Subspace', 'NumLearningCycles',30, 'Learners','knn', 'NPredToSample',28)`;
- **Ансамбль деревьев решений (TREE)** — `sklearn.ensemble.BaggingClassifier` с 30 деревьями — аналог `fitcensemble(..., 'Method','Bag', 'Learners','tree')`;
- **Полносвязная нейронная сеть (NeuralNetwork)** — `sklearn.neural_network.MLPClassifier`: один скрытый слой из 100 нейронов, активация `relu`, `alpha=0` (Lambda = 0), до 1000 итераций, стандартизация — аналог `fitcnet(..., 'LayerSizes',100, 'Activations','relu', 'Standardize',true)`;
- **Машины опорных векторов (SVC)** — класс `OneVsOneSVCPoly2`: ECOC one-vs-one из SVM с полиномиальным ядром 2-й степени, `C=1` (BoxConstraint), стандартизация — аналог `fitcecoc(..., templateSVM('KernelFunction','polynomial','PolynomialOrder',2,'BoxConstraint',1,'Standardize',true), 'Coding','onevsone')`.

Стандартизация признаков (анал `'Standardize', true`) выполняется обёрткой `StandardizedModel`.

### 4. Распознавание и оценка точности — `evaluate()`

Каждая модель применяется к дескрипторам тестовых изображений, для неё строится диаграмма ошибок (матрица путаницы, рисуемая `matplotlib` — аналог `confusionchart`) и в консоль выводится усреднённое значение точности классификации `Acc` (доля верных ответов — след матрицы, делённый на её сумму).

## Как использовать

1. Скачать один из наборов данных (notMNIST или Fashion MNIST PNG) и распаковать его так, чтобы внутри была папка с подпапками-классами.
2. Указать путь к этой папке в константе `DATA_DIR` (и при необходимости изменить `IMG_SIZE`, если изображения не 28×28).
3. Установить зависимости (см. «Требования»).
4. Запустить скрипт:

   ```bash
   python image_description_and_ml_recognition.py
   ```

5. По результатам оценить построенные матрицы путаницы и точность каждой модели; при желании выбрать другой дескриптор, изменив строку:

   ```python
   DESCRIPTORS = {"D_1": d1, "D_2": d2, "D_3": d3, "D_4": d4}["D_1"]
   ```

## Примечания

- Изображения предполагаются размером 28×28 пикселя (как в notMNIST/Fashion MNIST); размерности дескрипторов завязаны на это.
- В отличие от оригинального MATLAB-скрипта, здесь данные автоматически разделяются на обучающую и тестовую выборки (75/25, стратифицированно, `train_test_split`), поэтому точность измеряется на тестовой части, а не на тренировочной.
- Точность воспроизведения результатов MATLAB зависит от различий в реализациях алгоритмов (например, `MLPClassifier` vs `fitcnet`, `BaggingClassifier` vs ансамбль Bag в MATLAB); параметры моделей подобраны максимально близко к оригиналу.
